# Yaman Sahu — Portfolio

Personal portfolio website for **Yaman Sahu**, a full-stack developer and UI/UX
designer in Raipur, India. Built with the Next.js App Router.

## Pages

Home · About · Services · Portfolio · Blog · FAQ · Contact · Privacy

## Tech

- **Next.js 14** (App Router)
- **React 18**
- **Tailwind CSS** + a custom green/yellow design system
- **Framer Motion** (animations)
- `next/font` (Bricolage Grotesque, Plus Jakarta Sans, IBM Plex Mono)
- Per-page SEO: metadata, canonical, Open Graph, JSON-LD schema, `sitemap.xml`, `robots.txt`

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
```

## Build

```bash
npm run build
npm run start
```

## Project structure

```
app/            route pages (App Router)
components/     UI + home/layout components
data/           site config, projects, services, content, posts
public/assets/  screenshots and images
```
